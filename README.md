# 🌟 Maryam - Modern Single-Page Portfolio

A modern, fast, responsive single-page personal website and portfolio built with clean semantic HTML5, CSS3, and JavaScript.

## 🚀 Features
- 🎨 **Modern Design**: Glassmorphism UI, glowing ambient orbs, and gradients.
- 🌓 **Dark / Light Mode**: Instant theme switcher with `localStorage` memory.
- 📱 **100% Responsive**: Looks great on phones, tablets, and desktop displays.
- ⚡ **Zero Build Step**: Pure HTML/CSS/JS — deployable on Vercel with zero configuration.
- 📨 **Interactive Contact Form**: Client-side validation and feedback notifications.

## 📁 Project Structure
```text
├── index.html   # Main web page structure & content
├── style.css    # Responsive styles, themes & glassmorphism UI
├── script.js    # Theme toggle, mobile menu & interactive animations
└── README.md    # Documentation
```

## 🌐 Deploy to Vercel
1. Visit [vercel.com](https://vercel.com) and log in with your GitHub account.
2. Click **"Add New..."** -> **"Project"**.
3. Select this repository (`my-first-website`).
4. Click **"Deploy"** — and your website is instantly live! 🎉
